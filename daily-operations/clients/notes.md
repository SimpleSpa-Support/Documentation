# Notes

The **Notes** tab in a client's profile shows all of that client's appointment notes in one place.

Each note is saved in its appointment and also appears here, so you can view and edit any note at any time from a single place.

{% hint style="info" %}
Appointment notes for the same service and the same client appear in all of that client's future appointments.
{% endhint %}
