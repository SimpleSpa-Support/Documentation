# Clients

This section explains how you add and manage clients, and what you can find in each tab of a client's profile.

## In this section

* [Managing Clients](managing-clients.md): add, edit and merge clients, and add a credit card on file.
* [Files](files.md): the client **Files** tab.
* [Images](images.md): the client **Images** tab.
* [Notes](notes.md): all of a client's appointment notes in one place.
* [Appointments](appointments.md): every booking the client has in the system.
* [Transactions](transactions.md): every line item the client purchased through the SimpleSpa POS.
* [Packages](packages.md): the client's packages, balances and package uses.
* [Forms](forms.md): the client's completed forms, which you can view or download as a PDF.
