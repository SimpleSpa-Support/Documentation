# Forms

This section explains how to create intake forms, questionnaires and consent forms, assign them to services and send them to your clients.

## In this section

* [Managing Forms](managing-forms.md): add and edit forms.
* [Additional Settings](additional-settings.md): private forms, prompt once and copying a form.
* [Additional Questions (Form Editor)](additional-questions-form-editor.md): the question types you can add to a form.
* [Assigning to a Service](assigning-to-a-service.md): link forms to the services that need them.
* [Sending a Form](sending-a-form.md): send forms to clients automatically and review their responses.
