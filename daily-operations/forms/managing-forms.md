# Managing Forms

This page explains how to add and edit forms in SimpleSpa.

SimpleSpa has integrated forms, so you can quickly add your own custom intake forms, questionnaires and even consent forms that capture your client's signature.

## Adding a Form

{% stepper %}
{% step %}
### Open the Add Form prompt

Press the **Add Form** button.
{% endstep %}

{% step %}
### Enter a name and description

Enter the **Name** of the form and a description. Make sure the description clearly tells your client what the form is about.
{% endstep %}

{% step %}
### Save

Press **Save** to go to the Form Editor, where you add your questions.
{% endstep %}
{% endstepper %}

## Editing a Form

At any time, press the pencil button next to a form. A window opens where you can:

* Edit the **Name** and **Description**
* Change the order of your questions
* Remove questions you have added

Click **Edit** at the top of the popup to expand the editor and change the name, description and form settings.
