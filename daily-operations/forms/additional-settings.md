# Additional Settings

With your forms you can have the following additional settings if needed

<figure><img src="../../.gitbook/assets/Screenshot 2024-07-13 at 6.10.08 PM.png" alt=""><figcaption></figcaption></figure>

## Private Form

Enabling this will hide the form from your clients and will only show in the appointment window - this can be used for internal forms to be completed

## Prompt Once

Enabling this will only show the form if the client has never completed it

## Cloning/Copying a Form

To add a form that is using a similar format or template, you can use the Copy button when editing a Form, this will create a copy of the form in the system with the same fields, allowing you to edit the new form without having to create it again from scratch
