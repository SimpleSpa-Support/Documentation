# POS Terminal

This page explains how to add (board) a POS terminal so you can process credit cards from the SimpleSpa POS.

SimpleSpa is integrated with certified POS terminals through our certified merchant services providers. If you got a terminal from our partner processor, you can add it in a few steps.

{% stepper %}
{% step %}
### Open your location's payment settings

Go to **Settings → Locations → (your location) → Payments & Tax Rates**.
{% endstep %}

{% step %}
### Add the terminal

Click the ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FS2fcCGk8I5c8ArUEgxTa%2FAdd%20Terminal.webp?alt=media\&token=5fbce6d6-c20b-4e0d-bcc9-3952b3735618) button. A new window opens, pre-filled with your business information.
{% endstep %}

{% step %}
### Enter the terminal details

Enter the terminal's serial number and a label for quick reference in the POS.
{% endstep %}
{% endstepper %}

Your terminal is now boarded, and you can start processing credit cards from the POS with it.

{% hint style="warning" %}
Currently, only terminals issued by our certified merchant services can be boarded to SimpleSpa.
{% endhint %}
