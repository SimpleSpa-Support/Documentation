# Birthdays

**Upcoming Birthdays** on the dashboard helps you turn birthdays into visits. Instead of a plain list of names, every client comes with a suggested next step and the history you need to decide what to do.

## Suggested next steps

| Suggestion   | When it's shown                                          |
| ------------ | -------------------------------------------------------- |
| **Win back** | The client hasn't visited for a while.                   |
| **Welcome**  | The client has never booked.                             |
| **Wishes**   | The client visits regularly; just send your best wishes. |

## What each birthday shows

* Number of visits, total spent, average ticket and time since the last visit.
* A marker when the client already has an appointment booked before their birthday, so you can celebrate in person.
* A marker when the client has opted out of marketing or has no phone or email saved, so nobody is contacted by mistake.
* A badge for milestone birthdays and your highest-spending clients.

## Filter and export

* Show birthdays for **Today**, the next **7**, **30** or **90** days.
* Narrow the list to one suggested action.
* Excel and print exports follow what's on screen.

{% hint style="info" %}
The list shows how many of your clients have a birthday saved. If that number is low, add the date when you create a client or ask at checkout.
{% endhint %}

For a month-by-month view, see the Birthdays report in [Client Reports](../../reports-and-marketing/reports/client-reports.md).
