# Making a Sale

This page explains how to make a sale without an appointment.

{% stepper %}
{% step %}
### Open the POS

On the **Dashboard** or **Appointments** page, click the **Make a Sale** button or the **Shopping Cart** button in the top navigation menu. The POS window opens.
{% endstep %}

{% step %}
### Choose the payment method

At the top of the POS, select the primary payment method used.
{% endstep %}

{% step %}
### Set a client

Select the client for the sale.
{% endstep %}

{% step %}
### Add items

Select at least one service, product, gift card, or package to complete the sale.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
If you have connected your SimpleSpa account to a credit card processor, [read here](../pos/processing-credit-cards.md) to learn how credit cards are processed with SimpleSpa.
{% endhint %}
