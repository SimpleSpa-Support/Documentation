# Applying Discounts during Checkout

To apply a discount in a cart quickly make sure that all cart items have been added, then press the +Discount button which will bring up a section that you can apply either a preset discount or you can enter a custom percentage to the cart

## Applying a nominal Discount

Press the button with the % - $ to switch from percentage to nominal, when you set the amount it will apply the number value as a discount

<figure><img src="../../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

## Applying a saved discount profile

Discount Profiles are applied to client profiles, in the event you would like to quickly apply a saved discount profile that is not on this client profile click on the persons icon, this will bring a list of all discount profiles that you can use only for the specific cart

## Removing a Discount

Discounts can be removed by simply pressing the minus button in the discount line
