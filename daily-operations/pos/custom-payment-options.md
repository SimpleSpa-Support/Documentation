# Custom Payment Options

Besides Cash, Credit Card and Other, you can add your own payment options for each location: Venmo, Zelle, bank transfer, room charge, a QR payment, or anything else your business accepts.

## Add a custom payment option

{% stepper %}
{% step %}
### Open the location's payment settings

Go to **Settings → Locations → (your location) → Payments & Tax Rates** and find the accepted payment methods.
{% endstep %}

{% step %}
### Add the option

Add a new option, give it a name (for example **Venmo**) and pick an icon from the list.
{% endstep %}

{% step %}
### Arrange and save

Rename, reorder or remove options as needed, then save.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Each location can have up to **6** custom payment options.
{% endhint %}

## Take a payment with a custom option

Custom options appear as their own buttons in the POS payment row, next to **Cash**, **Credit Card** and **Other**. Select one and complete the sale as usual.

The sale is recorded under **Other**, tagged with the option you chose. Your existing totals and reports keep working the same way.

## Where custom options show up

| Place                       | What you see                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------ |
| **Receipt**                 | The option used for each payment, for example _Other (Venmo)_.                       |
| **Dashboard daily summary** | The **Other** total broken down by option. Untagged amounts show as **Unspecified**. |
| **Printed daily report**    | The same per-option breakdown.                                                       |
