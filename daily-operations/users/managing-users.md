# Managing Users

This page shows you how to add and edit users in SimpleSpa.

With our appointment scheduling software, you can have as many users as you need for free. For example, a front desk user does not count against your staff.

## Adding a user

Click the add user button, then enter the username, role and email.

See [User Roles](user-roles.md) for what each role can do.

## Edit a user

Click the user in your list of users. You can then update the user's password and login information.
