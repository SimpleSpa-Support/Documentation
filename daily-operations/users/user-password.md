# User Password

Selecting a user also lets you set that user's password manually. Enter the new password twice and save. Only Manager and Admin accounts can set another user's password.

{% hint style="info" %}
Every user can change their own password and turn on 2-step sign-in from **Account Security**. See [Account Security](account-security.md).
{% endhint %}
