# Selling Packages

This page explains how to sell a package in the SimpleSpa POS.

1. In the SimpleSpa POS, go to the **Packages** tab. You will see a list of all packages added to your account.
2. Select the package you want to sell. Its services and the quantity of credits are shown.

{% hint style="info" %}
If the client is linked to any services in the package, you will see a **-1 Credit** option. Use it to deduct one credit from the package during the sale.
{% endhint %}
