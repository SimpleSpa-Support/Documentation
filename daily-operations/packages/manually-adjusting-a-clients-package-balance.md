# Manually Adjusting a Client's Package Balance

This page explains how to change the remaining package credits a client has.

1. On the **Clients** page, select the client whose package balance you want to adjust.
2. Go to the **Packages** tab.
3. Press the pencil button to adjust the client's remaining credit balance.

For more details, [see Adjusting Client Package Balance from the Clients Packages Tab](../clients/packages.md).
