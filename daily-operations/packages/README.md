# Packages

This section explains how to create, sell and redeem service packages, adjust client package balances and set up memberships.

## In this section

* [Managing Packages](managing-packages.md): add and edit packages.
* [Selling Packages](selling-packages.md): sell a package in the POS.
* [Redeeming Packages](redeeming-packages.md): see a client's package credits when booking.
* Manually Adjusting Clients Package Balance: change a client's remaining credits.
* [Memberships](memberships.md): set up recurring memberships (requires Stripe).
