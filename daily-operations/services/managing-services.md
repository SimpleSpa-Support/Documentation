# Managing Services

This page shows you how to set up service categories and the services within them.

When you add a service, you set its specifics, including name, price, duration and notes, along with the other settings described in [Fields and Service Settings](fields-and-service-settings.md).

## Adding Service Categories

Every service must belong to a service category, so you need to create a category before you can add a service.

1. Click the **Add Category** ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2Fe1We57HvVaLZIaVlL74C%2FCategory.webp?alt=media\&token=aa27d35c-a41f-4c5b-a898-b0ef5908e456) button and enter a category name.
2. Once the category is added, it appears in the list below. Go to that category to add services to it.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FxgnFdbel3a8vFBHjz7Iz%2FScreenshot%202024-07-09%20at%205.38.00%E2%80%AFPM.png?alt=media&#x26;token=fd1f223c-df2e-4aaf-8654-b39a7df95925" alt=""><figcaption><p>The Add Category prompt</p></figcaption></figure>

## Editing Service Categories

To edit a service category, click the ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FsVkYSv2n1ZIDDJCx5qWv%2FPencil%20Button%2002.webp?alt=media\&token=0519b972-51ea-4143-ab13-899b82280f8f) button. In the popup, you can:

* Edit the category name.
* Set the category color coding. The color set here overrides the status color codes until an appointment has been paid/completed.
* Manage **Experience Levels**, which let you set experience-based or custom pricing that you can then assign to staff.

{% hint style="info" %}
Add all your services before you add experience levels.
{% endhint %}

If online booking is enabled for this business location, a chain icon appears in this prompt. Click the chain icon to get a direct permalink for the service category.

## Removing Service Categories

You can only remove a service category when it is not assigned to any provider and has no services in it.

1. On the **Staff** page, remove the service category from any staff it is assigned to.
2. Delete the services in the category, or move them to another category.
3. Remove the service category.
