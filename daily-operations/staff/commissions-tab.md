# Commissions Tab

This page explains how you set commission percentages per service category for a staff member.

Commissions are usually set once for all services/products in the main tab. If commissions vary by service category, you can set the percentage for each service category in the **Commissions** tab.

* Commissions are calculated and applied before tax, after any discounts.
* Commissions are calculated/assigned when gift certificates are redeemed.

{% hint style="info" %}
When you change commission values, the change applies to future sales, not to transactions that are already completed.
{% endhint %}
