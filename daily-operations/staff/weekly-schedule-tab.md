# Weekly Schedule Tab

Set a custom weekly schedule for any week by selecting the week, and then setting the days and time availability for that selected week, press the Save button to override the general calendar

<figure><img src="../../.gitbook/assets/Screenshot 2024-08-25 at 12.00.51 AM.png" alt=""><figcaption><p>Here you can override the selected staff weekly schedule, by pressing save this updated schedule will override the main schedule</p></figcaption></figure>

<figure><img src="../../.gitbook/assets/Screenshot 2024-08-25 at 12.01.42 AM.png" alt=""><figcaption><p>When there is a custom schedule, a red reset button will appear allowing you to reset the schedule back to the default staff availability</p></figcaption></figure>
