# Weekly Schedule Tab

This page shows you how to set a custom schedule for a staff member for a specific week.

1. Select the week.
2. Set the days and time availability for that week.
3. Click **Save**. The custom schedule overrides the general calendar for that week.

## Resetting a custom schedule

When a week has a custom schedule, a red reset button appears. Click it to reset the schedule back to the staff member's default availability.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FSQtmoru92bvfILbDMpL2%2FScreenshot%202024-08-25%20at%2012.01.42%E2%80%AFAM.png?alt=media&#x26;token=c89f7312-9a69-4dee-a80e-23ce7cba9d90" alt=""><figcaption><p>When there is a custom schedule, a red reset button appears so you can reset the schedule back to the default staff availability</p></figcaption></figure>
