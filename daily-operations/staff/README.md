# Staff

This section explains how you add and manage your staff/providers in SimpleSpa.

## In this section

* [Managing Staff](managing-staff.md): add, edit and export staff.
* [Fields and Settings](fields-and-settings.md): every field and setting available for a staff member.
* [Calendar](calendar.md): add an external calendar, such as Google Calendar, so its events show as blocks in SimpleSpa.
* [Commissions Tab](commissions-tab.md): set commission percentages per service category.
* [Weekly Schedule Tab](weekly-schedule-tab.md): set a custom schedule for a specific week.
* [Block Hours on Calendar](block-hours-on-calendar.md): block out hours in a day.
* [Breaks Tab](breaks-tab.md): set fixed breaks.
* [Clock In/Out Tab](clock-in-out-tab.md): review and edit clock in/out hours.
* [How to Clock In/Out](how-to-clock-in-out.md): how staff clock in and out from the dashboard.
* [Assigning Specialties](assigning-specialties.md): assign service categories so staff are bookable online.
* [Staff Login](staff-login.md): let staff log in and manage their schedule.
