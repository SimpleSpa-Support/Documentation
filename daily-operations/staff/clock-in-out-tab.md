# Clock In/Out Tab

This page explains how you review and manage a staff member's clock in/out hours.

Select any date to see the clock in/out hours for that day.

* **Edit:** Administrators and Managers can override the recorded hours by clicking the pencil button next to the hours.
* **Add:** To add a new set of clock in/out hours, click the ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FLBlqF20lUTaQmTeQWtXZ%2FAdd%20Clock%20in%20out.webp?alt=media\&token=0b04b573-624a-4e06-832f-682735372480) button to create a new default entry, which you can then edit to any time.

You can also edit clock in/out entries in this tab for any given day, and remove them if needed.
