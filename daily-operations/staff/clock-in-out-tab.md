# Clock In/Out Tab

Quickly refer to the Clock In/Out hours for any date selected, Administrators and Managers have the ability to override the hours set by pressing the pencil button next to the hours. To add a new set of Clock In/Out hours press the ![](<../../.gitbook/assets/Add Clock in out.webp>) button which will make a new default entry that can be edited to any time.
