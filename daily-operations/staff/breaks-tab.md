# Breaks Tab

This page shows you how to set a fixed break for a staff member.

In the **Breaks** tab of the **Edit Staff** prompt, select the date/hours for the break.

{% hint style="info" %}
Setting a break removes the staff member's online availability during that time.
{% endhint %}

You can also handle breaks on the appointments page by creating a block.
