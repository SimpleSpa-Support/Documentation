# Calendar

This page shows you how to add an external calendar to SimpleSpa.

Click the ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2F8XIs74dChXfA5JP71xet%2FCalendar%20Button.webp?alt=media\&token=e31b625a-3d89-4e08-ba77-6083379f2515) button and add the URL of your public calendar link. Appointments from the third-party provider show up as blocks in SimpleSpa.

## Google Calendar

For Google Calendar, use the **Secret address in iCal format** from the **Settings and sharing** options of the specific calendar. This syncs one way, from Google Calendar to SimpleSpa.

{% stepper %}
{% step %}
### Open Settings and sharing

In Google Calendar, open **Settings and sharing** for the specific calendar you want to sync to SimpleSpa.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FMEnsfbw5foXDYBpDhZ8t%2FScreenshot%202024-07-04%20at%2011.30.25%E2%80%AFPM.png?alt=media&#x26;token=a17817ff-6359-4799-9f57-ce12a4f2c42a" alt=""><figcaption><p>The Settings and sharing menu button for a specific calendar in Google Calendar</p></figcaption></figure>
{% endstep %}

{% step %}
### Copy the secret address

Go to **Secret address in iCal format** and use the copy button to copy the address.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FKU4s7KobENjdbYpS2jEc%2FScreenshot%202024-07-04%20at%2011.31.05%E2%80%AFPM.png?alt=media&#x26;token=516277df-4bfb-4757-8e4f-46fb875f7613" alt=""><figcaption><p>The Secret address in iCal format, found in Settings and sharing</p></figcaption></figure>
{% endstep %}

{% step %}
### Paste it in SimpleSpa

Paste the address in the URL section in SimpleSpa, and label the calendar with a memorable name.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FI45L1TYxmEcWxrKxCZM8%2FScreenshot%202024-07-04%20at%2011.32.35%E2%80%AFPM.png?alt=media&#x26;token=bb2afe73-f5bd-48d6-bc33-eee28ff8f17d" alt=""><figcaption><p>This is where you paste the iCal link above, in the URL section. Label the calendar with a memorable name.</p></figcaption></figure>
{% endstep %}
{% endstepper %}
