# Block Hours on Calendar

This page explains the two ways you can block out hours in a staff member's day.

* **Create a block:** This is the quickest way to block out hours in a day. See [Creating a Block](../appointments/creating-a-block.md).
* **Set a custom weekly schedule:** Set up a different daily schedule for any given day. See [Weekly Schedule Tab](weekly-schedule-tab.md).
