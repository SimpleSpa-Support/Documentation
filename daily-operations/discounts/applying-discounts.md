# Applying Discounts

This page explains how to assign a discount profile to a client and how to apply a discount in the POS.

## Assigning a Discount to a Client

1. On the **Clients** page, press the edit client button to open the client's profile.
2. In the **Edit Client** prompt, press the **+Discount** button and choose a discount profile.

From then on, the POS automatically prompts you to apply this discount to the cart when you check out this client.

## Applying a Discount for a Single Sale

If a client doesn't have a discount profile assigned, you can still apply one to a single sale:

1. In the POS, press the **+Discount** button.
2. Press the people icon. A discount profile prompt opens.
3. Select the profile to apply to this cart.

{% hint style="info" %}
This is a one-time use. The profile is not saved to the client's profile for future checkouts.
{% endhint %}
