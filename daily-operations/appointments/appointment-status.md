# Appointment Status

Every appointment has a status. This page explains which statuses SimpleSpa sets automatically and how to change a status yourself.

## Changing a status

To change an appointment's status, click the appointment and then use the blue dropdown in the upper right of the popup.

## Statuses set automatically

| Status        | When it is set                                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **New**       | When an appointment is created in SimpleSpa.                                                                                               |
| **Online**    | When a client books the appointment online.                                                                                                |
| **Paid**      | When the appointment is completed directly with the **Pay Now** button.                                                                    |
| **Confirmed** | When the client confirms the appointment from their notification (if the \[CONFIRM] tag is used in the email or SMS appointment reminder). |
| **Cancelled** | When the client cancels from their reminder link (if the \[CONFIRM] tag is used).                                                          |

## New appointments

When you create an appointment in SimpleSpa, its status is set to **New**. At the end of the booking wizard, you can choose to mark the appointment as confirmed.

If Text/SMS is enabled for your business, a confirmation text with the booking information goes to the client's number within 5-10 minutes of the booking being completed.

## Online appointments

When a client books online, the appointment status is set to **Online**. To change it, click the appointment and change the status in the upper right of the appointment popup.

## No-shows and cancellations

If a client does not show up for their appointment, select the **NO-SHOW** status.

{% hint style="info" %}
The **NO-SHOW** and **CANCELLED** statuses open up that time slot on your calendar for potential online bookings.
{% endhint %}
