# Cloning a Block

This page explains how to copy a block, copy it to all staff, and set up a recurring block schedule.

## Editing or copying a block

Click a block that you have already created. You can then:

* Edit the description.
* Delete the block.
* Copy (clone) the block, which creates a duplicate block for the same date and time.

After you make a copy, you can drag it to another staff member. If the calendar is set to **Weekly View**, you can also drag the block to another date.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FSvzcVgDBDbVgykPPrdqI%2FScreenshot%202024-07-04%20at%202.18.57%E2%80%AFPM.png?alt=media&#x26;token=8034cb53-3a09-4a38-9b79-8732827cbbcb" alt=""><figcaption><p>The Block Editor</p></figcaption></figure>

There are two ways to clone a block:

* **Orange button:** Makes a single copy that you can then move to any column or slots you need.
* **Red button:** Copies the block to all staff.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FYFGSL4KTOXeRSqkm4GVI%2FScreenshot%202024-07-04%20at%202.19.12%E2%80%AFPM.png?alt=media&#x26;token=1ba59ba9-bf0d-4663-86e3-848edf31d442" alt=""><figcaption><p>Copy Block button</p></figcaption></figure>

## Setting a block schedule

Blocks support schedules too. Select **Set Schedule** to choose how the block should recur.

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2Fgelv2U75jFFLjxgQOIyh%2FScreenshot%202024-07-04%20at%202.19.38%E2%80%AFPM.png?alt=media&#x26;token=28d0b08e-3f38-4e55-8929-970db22cc8b5" alt=""><figcaption><p>The Block schedule setup button</p></figcaption></figure>

You can set a recurring block's frequency and number of visits/times. You can also set an optional end date, so you don't have to calculate the number of "visits".

<figure><img src="https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FXF9GXPMkBzWNOH453Caa%2FScreenshot%202024-07-04%20at%202.19.25%E2%80%AFPM.png?alt=media&#x26;token=96e818be-30b0-4f28-b4f2-db62b6bed973" alt=""><figcaption><p>Block Schedule setup</p></figcaption></figure>

The example below creates a block that repeats every week for the next two weeks, on the same day of the week the block was created. For example, if the block was created on a Thursday, it is added for this staff member on the next 2 Thursdays.
