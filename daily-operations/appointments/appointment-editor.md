# Appointment Editor

When the New UI is on, clicking an appointment on the calendar opens the Appointment Editor. Everything about the booking is in one window, organised in tabs.

{% hint style="info" %}
To turn on the editor, use the wizard toggle in the calendar toolbar. See [Switching to the New UI](../../get-started/new-ui.md).
{% endhint %}

## The tabs

| Tab              | What you'll find                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Summary**      | Client card, cost and payments, forms, photos, card on file, message delivery status and meeting links.                               |
| **Edit**         | Change the service, staff, date, time, duration or client.                                                                            |
| **Notes**        | Notes for this appointment and earlier notes for the same service.                                                                    |
| **Transactions** | Payments linked to this appointment.                                                                                                  |
| **Audit**        | Every status change, who made it and when. Online bookings start with a **Booked Online** row (or **Booked Online (Staff Request)**). |

## Change the status

Click the status pill at the top of the editor. A row of coloured status chips appears. Click one to change the status instantly.

## Contact the client

Click the client's contact details to open the contact options: **Call**, **SMS**, **WhatsApp**, **Viber**, **FaceTime**, **Copy**, **Share** or save as a **vCard**.

## What the Summary tab shows

* **Cost and payments:** the service cost, the amount paid, and either the balance due (in red) or **Fully paid** (in green). For locations that add tax on top, tax is shown separately.
* **Credit or balance:** if the client has account credit or owes money, a pill in the client card shows it: blue for credit, red for a balance owed.
* **Card on file:** the saved card, or a **Capture Card** button.
* **Delivery status:** whether the SMS and email confirmations were delivered.
* **Meetings:** add or remove a Zoom or Google Meet link. See [Meetings Integration](meetings-integration/).
* **Forms and photos:** thumbnails of completed forms and appointment photos.

## Package on file

If the client has a package, a package card shows the credits remaining and the expiration date, with two actions:

* **Charge Package Now** uses a package credit for this appointment.
* **Add / Adjust Tip** adds a tip to the package charge.

## Change the client on an appointment

Use this when an appointment was booked under the wrong client, or to turn a walk-in into a named client.

{% stepper %}
{% step %}
### Open the Edit tab

In the editor, open **Edit** and find the client row.
{% endstep %}

{% step %}
### Choose the new client

Click **Change** and search for the client.
{% endstep %}

{% step %}
### Save

Click **Save**. The change only takes effect when you save.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
You can't change the client once the appointment has been paid or has a package attached.
{% endhint %}
