# Creating an Appointment

This page explains the three ways to book an appointment in the classic calendar, including two quick booking wizards.

{% hint style="info" %}
If you use the New UI, you can switch to the [New Appointment Wizard](new-appointment-wizard.md) with the wizard toggle in the calendar toolbar. It walks you through Service → Staff → Date & Time → Client → Confirm. The classic wizards described below are still available.
{% endhint %}

## Book directly from the calendar

Click any available white slot in a staff member's column on the calendar to open the appointment wizard. This is the fastest way to book. You choose the service, add the client, and then confirm the booking.

{% stepper %}
{% step %}
### Select a time

Click any available white area on the appointments page. The slot you click sets the start time.
{% endstep %}

{% step %}
### Choose a service

The **Appointment Wizard** popup appears. Select a service. As SimpleSpa learns from your bookings, your top 10 services appear in the top section.
{% endstep %}

{% step %}
### Add the client and appointment notes

* **Clients:** Search for a client by name or mobile number. If the client does not exist, press **Add Client** to add a new client.
* **WalkIn:** To add a booking quickly without entering a client, use the **WalkIn** button. This creates a booking for a walk-in.
* **Notes:** These are appointment notes for this client's appointment. They appear again when the client books the same appointment in the future, along with any other notes taken for the same service.
{% endstep %}

{% step %}
### Confirm the booking

Review the booking information and the client's past booking history, then confirm.
{% endstep %}
{% endstepper %}

## Book with the Plus button

The **Plus Button** ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FmPLA6cQeJlFhJHzexsDZ%2FPlus%20Button.webp?alt=media\&token=00203711-c37a-4118-aaae-70d66de610bc) in the top left opens another easy wizard:

1. Select the service category.
2. Select a service within that category.
3. Select the staff member who specializes in that service.
4. Select a date and time based on availability.
5. Search for the client or enter their information.
6. Confirm and make the booking.

## Book multiple services with the Multi button

The **Multi Button** ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FfqsA0Qngn2uMZa3Anxok%2FMulti%20Button.webp?alt=media\&token=1a985b38-df2b-4340-b556-84f1be0220bf) lets you create appointments for several services for the same client from a single window. For example, a client may want both hair and nails, and you can book both here at once.

{% hint style="info" %}
If a client is booked for multiple services on the same day, the POS/Checkout detects this automatically, adds all the services, and completes all the appointments.
{% endhint %}
