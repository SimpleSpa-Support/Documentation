# Searching Appointments

The appointment search opens as a side panel on a computer and as a sheet from the bottom of the screen on a phone, so the calendar stays in view.

{% stepper %}
{% step %}
### Open search

On the **Appointments** page, click the search icon in the calendar toolbar.
{% endstep %}

{% step %}
### Type what you're looking for

Search by client name, service or phone number.
{% endstep %}

{% step %}
### Filter the results

Choose **Upcoming**, **Past** or **All**. Click a result to open that appointment.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
**Past** and **All** look back about two years. For a client's complete history, open their profile and use the [Appointments](../clients/appointments.md) tab.
{% endhint %}
