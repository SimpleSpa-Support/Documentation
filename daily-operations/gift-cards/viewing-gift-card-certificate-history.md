# Viewing Gift Card/Certificate History

This page explains how to see where a gift card or gift certificate has been redeemed.

Each time a gift card or gift certificate is used, it is applied to a transaction. To view its redemption history, use either option:

* **From the POS:** Open the POS and press **+Gift Certificate**. Enter the voucher number and press **Apply**. If the number is valid, the current balance appears. Click the ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FX4zkuib7uaEWycr4dpks%2FHistory%20Gift%20Button.webp?alt=media\&token=ada36d6f-2c80-4b8e-be27-0f8e016656a7) button to see the history. This button only appears if the card/certificate has been used.
* **From the Gift Certificates page:** Open the **Gift Certificates** page from the left menu and click any gift certificate template. Search and filter the list, then press the ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2FzBtjWU2BlkXbL4edC7zv%2FMagnifying%20Glass.webp?alt=media\&token=323574ab-e39a-47c0-82e5-20400c64dab0) button to view a list of the invoices the code was redeemed on.
