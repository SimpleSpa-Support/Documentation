# Viewing Gift Card/Certificate Balance

This page lists the ways you can check the current balance of a gift card or gift certificate.

When a gift card or gift certificate is first sold, it has a starting balance. The balance goes down each time it is redeemed. To quickly view the balance, use any of these options:

* **From the POS:** Open the POS and press **+Gift Certificate**. Enter the voucher number and press **Apply**. The current balance of the gift card/certificate appears.
* **From the Gift Certificates page:** Go to the **Gift Certificates** page, select the gift certificate template, and press the **Gift Certificates Sold** tab. You can view or search all gift certificates with their initial and current balance.
* **From Reports:** Go to **Reports → Transactions**, set a start and end date, and enter **limit gift certificates** in the search box. Gift cards/certificates appear in the format \*\*CODE\*\*, with a send button next to each one if you need to resend it.
* **From the client profile:** If the gift card was sold to a client (not a walk-in), go to **Clients →** (the client who bought it) **→ Transactions** tab. You will see all transaction items. Gift cards/certificates appear in the format \*\*CODE\*\*, with a send button next to each one if you need to resend it.
