# Products

This section explains how to set up and manage the retail products you sell in SimpleSpa.

## In this section

* [Managing Products](managing-products.md): add and edit product categories, products and product images.
* [Fields and Products Settings](product-fields-and-settings.md): the fields and settings available for each product.
* [Assign Tax Rate to all Products](assign-a-tax-rate-to-all-products.md): apply one tax rate to all existing products.
* [Inventory](inventory.md): add and remove stock for a product.
* [Orders](orders.md): create multi-product orders and apply them to your inventory.
* [Vendors](vendors.md): add and manage the vendors you buy from.
