# Orders

This page explains how to create a multi-product order and apply it to your inventory.

Use the **Orders** tab on the **Products** page to create an order that contains several products.

## Creating an Order

1. Press the ![](https://695085455-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fa9tSKQ7Cexg8YEba5Evb%2Fuploads%2F9TLoWTnSXlwYPVk8DhGJ%2FOrder%20Button.webp?alt=media\&token=83cb92e2-c1dd-4654-8bd2-21859e60b3ab) button.
2. Enter the required fields: the **Vendor** and the list of products to add to the order.

{% hint style="info" %}
Creating an order does not change your standing inventory yet. You need to apply the order first.
{% endhint %}

## Applying or Cancelling an Order

Click a standing order to apply or cancel it:

* **Apply**: updates the stock level of every product in the order in your existing inventory.
* **Cancel**: cancels the order without changing your existing inventory.
