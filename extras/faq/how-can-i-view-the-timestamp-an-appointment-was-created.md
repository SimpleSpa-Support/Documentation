# How can I view the timestamp an appointment was created?

To check the creation date of an appointment, go to the Dashboard or Appointments page. Select the appointment and hover over the info icon in the Appointment prompt. This will display the creation timestamp

Blocks also include timestamps to log their creation times in the system
