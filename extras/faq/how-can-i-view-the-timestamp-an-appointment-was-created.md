# How can I view the timestamp an appointment was created?

You can see when an appointment was created by hovering over the info icon in the Appointment prompt.

## View an appointment's creation time

1. Go to the **Dashboard** or **Appointments** page.
2. Select the appointment.
3. Hover over the info icon in the Appointment prompt to display the creation timestamp.
