# Selling Packages

To utilize the SimpleSpa POS for making a sale, begin by navigating to the 'Packages' tab. Here, you'll find a comprehensive list of all available packages currently in added to your account. To proceed with a sale, simply select the desired package. This action will reveal the associated services, along with the quantity credited.

If the client is linked to any services within the package, you'll notice a '-1 Credit' option. This feature allows for the deduction of a single credit from the package during the sale, streamlining the process.
