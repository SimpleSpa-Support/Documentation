# Managing Discounts

Discounts have been designed to provide an easy to assign a discount profile to a client, the use case is for set of clients that are part of a group that you would like provide a discount to, i.e. a VIP member discount that provides a 10% discount to purchases made during checkout

## Add Discount Profile

<figure><img src="../../.gitbook/assets/Screenshot 2024-07-14 at 11.41.24 AM.png" alt=""><figcaption><p>The Add Discount Profile button in the Discount Profile page</p></figcaption></figure>

<figure><img src="../../.gitbook/assets/Screenshot 2024-07-14 at 11.42.37 AM.png" alt=""><figcaption><p>The Add Discount Profile Prompt</p></figcaption></figure>

Currently the default setting is applying the percentage or amount to both all services & products in the clients cart during checkout. If you would like to customize to have this applied only to services or only to products please set the discount profile up first and then reach out to the support team to adjust this profile for you. You will need to provide the exact discount name and if this should apply only to products or only to services

## Edit Discount Profile

To edit a discount profile visit the Discount Profile page and then hit the pencil button to bring up the Edit Discount Profile
