# Calendar

You can add an external calendar to SimpleSpa, press the ![](<../../.gitbook/assets/Calendar Button.webp>) button, and you can add the url for your public calendar link; For Google Calendar, you can use the Secret address in iCal format in the Settings and sharing options of the specific calendar. Appointments from the third party provider will show up as blocks in SimpleSpa.

## Google Calendar

Using Google Calendar you can quicklly get this secret address in iCal format by going to Settings and sharing for the specific calendar you would like to sync one way towards SimpleSpa, from there go to the Secret address in iCal format and use the copy button to copy the address, this is the address that you will use to paste in SimpleSpa
