# Adding Form(s) to Services

You can add existing form or forms to the service, select the service you would like to add a form and then press the ![](<../../.gitbook/assets/Form Button.webp>) button, once a form has been added, any appointments booked for that service will now include the forms. If a service has been booked online the respective forms will automatically show at the end of the online booking process. Emails can include forms using the \[FORMS] tag in the email reminder and online booking templates, see [sending forms](../forms/sending-a-form.md) for more details
