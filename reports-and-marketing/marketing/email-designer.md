# Email Designer

The Email Designer builds your campaign email from blocks. Click any block to edit it in the side panel and see your changes straight away. You don't need any design or HTML knowledge.

## Choose a layout

Start from **Simple**, **Offer**, **Photo** or **Newsletter**. You can switch layouts at any time; your text, photos and links are kept.

## Edit and arrange blocks

* **Edit:** click a block and change it in the side panel.
* **Move, copy or delete:** hover over a block, or use the buttons in the side panel.
* **Add:** new blocks are added below the block you've selected.

| Block            | Use it for                                        |
| ---------------- | ------------------------------------------------- |
| **Logo**         | Your business logo.                               |
| **Headline**     | The main message.                                 |
| **Text**         | Paragraphs of text.                               |
| **Image**        | A photo, with a description and an optional link. |
| **Button**       | A call to action, such as **Book now**.           |
| **Offer**        | A highlighted discount or promotion.              |
| **Divider**      | A line between sections.                          |
| **Social links** | Links to your social media pages.                 |

## Images

Upload an image, use your logo, or paste an image address. Add a short description to every image; it's shown when an email app blocks images.

## Brand color and preview

Set your **brand color** to style headlines and buttons. Switch between **Desktop** and **Phone** to see how the email looks on each.

{% hint style="info" %}
Your logo, business details and an unsubscribe link are added to every email automatically.
{% endhint %}

## Custom HTML

If you prefer to write your own design, the HTML editor is still available. Designs made with blocks reopen block by block, so you can keep editing them later.
