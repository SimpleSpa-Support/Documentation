# Linking & Embedding Online Booking

Online booking is available to subscribed accounts. You can use it as a link, or embed it directly in your website.

## Link

You'll find the link to your online booking page in **Settings → Locations → (your location) → Website Tools**.

## Button Code

SimpleSpa provides easy-to-use button code that you add directly to your website HTML to link to your online booking. You can customize the button to match your styling by editing the CSS in the HTML code.

## Embedding / iFrame Booking

You can embed the booking experience directly in a dedicated page on your website with a single line of code. The page where you add the embed code shows only the booking process to your visitors.
