# Custom Theme & Fonts

Each location can have its own online booking theme, so the booking page matches your website and brand.

## What you can change

| Setting           | What it changes                                                                              |
| ----------------- | -------------------------------------------------------------------------------------------- |
| **Colours**       | Buttons, highlights, backgrounds and text.                                                   |
| **Fonts**         | Headings and body text. You can use any font from [Google Fonts](https://fonts.google.com/). |
| **Corner radius** | How rounded buttons and cards are, from square to fully rounded.                             |
| **Custom CSS**    | Any further styling for advanced changes.                                                    |

{% hint style="info" %}
Locations without a custom theme keep the standard SimpleSpa look. Nothing changes until you add one.
{% endhint %}

## Set up a custom theme

{% stepper %}
{% step %}
### Gather your brand details

Note your brand colours (as hex codes such as `#185FA5`), the Google Fonts you use, and how rounded you'd like buttons to be.
{% endstep %}

{% step %}
### Send them to support

Contact SimpleSpa support with the location name and your brand details, plus any custom CSS.
{% endstep %}

{% step %}
### Check your booking page

Open your booking page and make a test booking to see the new look. See [Your Custom Booking URL](your-custom-booking-url.md).
{% endstep %}
{% endstepper %}
