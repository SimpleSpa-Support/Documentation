## The report layout

| Part               | What it does                                                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date range**     | One control for the whole report: **This month**, **Last month**, **90 days**, **12 months** or **Custom**. You can also compare with last year or the previous period. |
| **Headline tiles** | The key numbers for the period, each showing whether it went up or down compared with the period you chose.                                                             |
| **Chart**          | A single chart of the main trend.                                                                                                                                       |
| **Detail table**   | The rows behind the numbers.                                                                                                                                            |
| **Download CSV**   | Downloads the table to open in Excel or Google Sheets.                                                                                                                  |
| **Print**          | Prints the report on screen.                                                                                                                                            |

## Print a report

Click the print icon (**Print this report**) next to **Download CSV**. The printout includes your business name, the date and time it was printed, the report title and date range, the tiles, the chart and the table. Buttons and menus are left off.

{% hint style="info" %}
On reports that load their table one page at a time (Transactions, Product Inventory and Client Revenue), only the page on screen is printed. To print more, show more rows per page first.
{% endhint %}

## Good to know

* Most numbers include today. The **Where it came from** bar on Revenue, the tiles on Transactions and Staff Sales, the revenue line on Expenses and the Forecast are updated overnight and run through yesterday.
* **Birthdays** has its own month picker because it looks ahead rather than back.
* **Client At-Risk** has its own print button.
