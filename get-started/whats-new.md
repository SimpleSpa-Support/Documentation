# What's New

SimpleSpa updates automatically, so there is nothing to download. Each entry below lists what changed and links to the guide that shows you how to use it.

{% hint style="info" %}
Some of the newest screens (the new dashboard, calendar look, booking wizard and appointment editor) are part of the **New UI**. See [Switching to the New UI](new-ui.md) to turn it on.
{% endhint %}

{% updates format="full" %}
{% update date="2026-10-07" %}
## Export clients to Mailchimp or any email tool

* **Export to Mailchimp** from inside a new campaign. Your API key is never stored on our servers, existing contacts are updated instead of duplicated, and only clients who allow marketing email are sent.
* **Download a file for another email tool** such as Constant Contact, Klaviyo or Brevo, with step-by-step import instructions.

[Exporting Clients to Email Tools](../reports-and-marketing/marketing/exporting-clients-to-email-tools.md)
{% endupdate %}

{% update date="2026-10-05" %}
## New campaign designer, templates and a send checklist

* **Campaigns list** with headline numbers, status filters and a one-click **Duplicate**.
* **New Campaign checklist**: To, Subject, Email, Text message and Send for review, each with a clear status. Email and text are both optional.
* **Audience cards**: Haven't visited lately, Birthdays this month, Top spenders, Most frequent and Everyone, each with a live count.
* **Block email designer** with layouts, brand color, images and a phone preview.
* **15 ready-made templates** and a **Before you send** check that catches leftover sample text and wrong links.
* **Revenue report** now uses live numbers that match the dashboard Daily Report.

[Creating a New Campaign](../reports-and-marketing/marketing/creating-a-new-campaign.md) · [Email Designer](../reports-and-marketing/marketing/email-designer.md) · [Campaign Templates](../reports-and-marketing/marketing/campaign-templates.md) · [Revenue & Sales Reports](../reports-and-marketing/reports/revenue-and-sales-reports.md)
{% endupdate %}

{% update date="2026-10-01" %}
## All reports redesigned, plus Client At-Risk

* Every report now shares one date range control, headline tiles, a chart, **Download CSV** and **Print**.
* **Client At-Risk** lists regular clients who are overdue for their next visit, ranked by how much they are worth to you.

[Reports](../reports-and-marketing/reports/) · [Client At-Risk](../reports-and-marketing/reports/client-at-risk.md)
{% endupdate %}

## Forecast

A new **Forecast** tab in Reports projects next month's (or the rest of this month's) revenue and appointments, with a likely range and a confidence rating.

[Forecast](../reports-and-marketing/reports/forecast.md)

## Deposits and cards on file

* Checking out an appointment with a deposit now always uses the appointment as it is today: the current service, price, staff and remaining balance.
* Bookings with several deposits now show every service at checkout.
* The saved-card safety check ignores formatting differences, so it only warns when a card really looks like it belongs to someone else.

[Balances & Deposits](../daily-operations/pos/balances-and-deposits.md) · [Cards on File](../daily-operations/pos/cards-on-file.md)
