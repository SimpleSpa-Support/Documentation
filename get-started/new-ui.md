# Switching to the New UI

SimpleSpa has a refreshed set of screens that you can turn on when you're ready. The classic screens stay available, and you can switch back at any time.

## What the New UI includes

| Area         | What changes                                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| Dashboard    | A cleaner dashboard layout.                                                                                                   |
| Calendar     | A lighter calendar with clearer staff column headers, gridlines and a **Today** button.                                       |
| Booking      | The [New Appointment Wizard](../daily-operations/appointments/new-appointment-wizard.md) replaces the classic booking window. |
| Appointments | Clicking an appointment opens the [Appointment Editor](../daily-operations/appointments/appointment-editor.md).               |

## Turn on the new dashboard and calendar look

{% stepper %}
{% step %}
### Open the menu

On the dashboard, click the **⋮** menu at the top right.
{% endstep %}

{% step %}
### Choose New UI

Select **New UI**. The dashboard and calendar reload with the new look.
{% endstep %}
{% endstepper %}

## Turn on the new booking wizard and appointment editor

{% stepper %}
{% step %}
### Go to the calendar

Open **Appointments**.
{% endstep %}

{% step %}
### Use the wizard toggle

Click the wizard toggle button in the calendar toolbar to switch between the new wizard and the classic booking flow.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
These choices are saved on each computer or tablet. If your front desk uses several devices, switch each one.
{% endhint %}
