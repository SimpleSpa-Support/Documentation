# Creating your first Appointment

Adding an appointment in SimpleSpa is quick.

1. Go to the **Appointments** page.
2. Click the time slot you want. The appointment wizard opens so you can complete the booking.

For more detail, see [Creating an Appointment](../daily-operations/appointments/creating-an-appointment.md).

{% hint style="info" %}
You can also switch to the New Appointment Wizard with the wizard toggle in the calendar toolbar. See [New Appointment Wizard](../daily-operations/appointments/new-appointment-wizard.md).
{% endhint %}
