# Mobile Device Support

This page explains how SimpleSpa works on phones and tablets and how to book appointments on a touch screen.

SimpleSpa is responsive and works on both Android and iOS (iPhone and iPad). When you install SimpleSpa as an app and open it from the SimpleSpa icon, the browser navigation bar no longer shows. The SimpleSpa app (PWA) always stays as up to date as the full browser version of SimpleSpa.

## Creating a new appointment on a touch-enabled device

Selecting a time slot on the **Appointments** page works slightly differently than on a computer:

1. Scroll up or down to the time you want.
2. Long-press the time slot for 2 seconds until it is highlighted in blue.
3. Release, then complete the booking with the wizard.

{% hint style="warning" %}
Because PWAs are sandboxed (they run in their own secure, limited container), some elements, such as form links and URL navigation, may not work the same way they do in a normal browser. If you have trouble navigating, switch back to your device's regular browser.
{% endhint %}
